# Project-Sales-Analysis
Analyzing data from sales company

This project demonstrates data cleaning and sales analysis using Python and pandas.

## Features
- Handle missing values
- Remove duplicate records
- Calculate revenue
- Analyze revenue by category and customer
- Find the best sales month
- Generate basic business insights

## Technologies
- Python
- pandas

## Skills Demonstrated
- Data cleaning
- Data analysis
- GroupBy operations
- Datetime handling
- Business insight generation
